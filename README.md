# The Farmer Was Replaced — build library

Website for personal reconstructed builds. This is separate from the publisher’s official release.

## Deploy on Render

Create a Static Site connected to this repository, branch `main`, build command `true`, publish directory `dist`. Alternatively create a Blueprint using `render.yaml`.

Downloads are hosted as GitHub Release assets; the website links to them directly. This repository and its published downloads are public.

macOS launch was verified. Windows compilation/archive integrity were checked, but Windows gameplay has not been tested. No iOS build is available.
